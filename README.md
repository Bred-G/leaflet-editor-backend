Leaflet Editor Backend

Бэкенд-сервис для создания, редактирования и экспорта листовок на основе XML-шаблонов. Предоставляет REST API для управления проектами, шаблонами и экспортом в различные форматы (PNG, JPEG, PDF, SVG).

Особенности

- Хранение листовок в формате XML, содержащем полный перечень характеристик макета (размеры, элементы, стили, слои)
- Возможность экспорта листовок в несколько форматов: PNG, JPEG, PDF, SVG
- В качестве основной базы данных используется PostgreSQL. Все проекты, шаблоны и метаданные пользователей сохраняются с поддержкой целостности и миграций через Alembic
- Полная асинхронность бэкенда за счёт использования асинхронного кода на базе async/await Python на всех уровнях приложения
- Наличие автоматически созданной документации API, доступной в двух форматах: Swagger UI и ReDoc

Технологии

FastAPI — современный веб-фреймворк
SQLAlchemy 2.0 — асинхронная ORM
PostgreSQL — основная база данных
Alembic — миграции базы данных
Pydantic — валидация данных
xmltodict — работа с XML
